# Agenda de Contactos en Python

Este es un proyecto simple de una **agenda de contactos** implementada en Python. El programa permite al usuario gestionar contactos, como agregar, buscar, modificar, eliminar y mostrar todos los contactos registrados.

Cada contacto incluye los siguientes detalles:
- **Nombre**
- **Número de teléfono**
- **Correo electrónico**
- **Cumpleaños (DD/MM/AAAA)**

## Funcionalidades

- **Insertar nuevo contacto**: Permite agregar un nuevo contacto con nombre, correo, teléfono y fecha de cumpleaños.
- **Buscar contacto**: Permite buscar un contacto por su nombre.
- **Modificar contacto**: Permite modificar los datos de un contacto ya existente.
- **Eliminar contacto**: Permite eliminar un contacto de la agenda.
- **Mostrar todos los contactos**: Muestra la lista completa de contactos registrados.
